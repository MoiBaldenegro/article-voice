# Código de conducta

Este proyecto adopta el **Contributor Covenant, versión 2.1**:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ (texto completo y traducción al español).

## En resumen

- Trato respetuoso y acogedor con todas las personas, sin importar experiencia, origen o identidad.
- Críticas sobre el código y las ideas, nunca sobre las personas.
- No se toleran acoso, insultos, ataques personales ni la publicación de datos privados de otros.

## Cómo reportar

Por el canal privado del repositorio en GitHub (contacto con los mantenedores desde el perfil del
repo). Los reportes se tratan con confidencialidad. Los mantenedores aplican las pautas de
cumplimiento del Contributor Covenant: corrección, advertencia, suspensión temporal o expulsión
permanente, según la gravedad.
