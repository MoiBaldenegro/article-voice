# ADR-0005 · pnpm como gestor de paquetes

- **Estado:** Aceptado
- **Fecha:** 2026-11-20

## Contexto

05 y 06 usan pnpm. Un lockfile único y reproducible es requisito de la cadena de suministro (ver
[modelo de amenazas](../modelo-de-amenazas.md)).

## Decisión

- pnpm, con la versión fijada en `packageManager` de `package.json` (Corepack).
- `pnpm install --frozen-lockfile` en CI; el lockfile siempre se commitea.
- La versión mínima de Node se declara en `engines` y se prueba en CI (ver [CI/CD](../../07-operacion/ci-cd.md)).

## Alternativas consideradas

| Opción | Por qué no |
| --- | --- |
| npm | Funciona, pero rompe la consistencia del repo |
| yarn | Sin ventaja clara para un solo paquete |

## Consecuencias

- Quien contribuya necesita Corepack (`corepack enable`), documentado en [onboarding](../../07-operacion/onboarding.md).
- Los usuarios del paquete pueden instalarlo con cualquier gestor: esto solo afecta al desarrollo.
