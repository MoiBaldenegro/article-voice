# Postmortems

Se escribe uno por cada incidente que afectó a usuarios (versión rota, vulnerabilidad,
publicación comprometida) o que estuvo cerca de hacerlo.

**Sin culpables:** se analizan el sistema y el proceso, no a las personas. La pregunta es "¿qué
permitió que pasara?", nunca "¿quién lo hizo?".

- Plantilla: [0000-plantilla.md](0000-plantilla.md).
- Nombre: `AAAA-MM-DD-<resumen>.md`.
- Cada acción correctiva es un issue con responsable y fecha.
